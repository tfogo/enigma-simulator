# Media and attribution inventory

Reviewed 27 September 2026 for the first learning release.

- Application code and original guide text use the repository's MIT license, already declared in package metadata and now supplied in `LICENSE`. Source acknowledgements do not imply endorsement.
- The logo, circuit diagram, keys, lamps, and rotor illustrations are repository-authored SVG/CSS/HTML. No museum photographs, document scans, audio, or video are copied into the site.
- Historical explanations are original summaries with contextual links to their sources. The 1930 runnable example and other engine fixtures retain source IDs, settings, raw letters, and provenance; surrounding source prose and imagery are not reproduced. See `docs/sources.md` and the fixture manifest.
- React, React DOM, and Scheduler are bundled in the frontend under MIT terms. Their installed-version license texts are retained in `web/public/THIRD_PARTY_NOTICES.txt`, copied into the production output. Refresh these notices when upgrading those runtime packages.
- DM Sans, DM Mono, and Libre Caslon Display are requested through Google Fonts CSS. Font files are not redistributed in the repository. System fonts provide fallbacks when external requests fail. The site therefore contacts Google Fonts when allowed; it is not wholly self-contained/offline. Any later self-hosting change needs to include each font's license and credit.
- Documentation screenshots show this project's own interface and sample messages. They include no user or participant data.

This inventory covers material currently shipped, not permission for future assets. New third-party images or long extracts require their own rights and attribution record. No review of unseen archival originals or endorsement by source institutions is claimed.
